# Правки русского текста

Названия брендов, данные заведений, английские и грузинские переводы сохранены.

Основные составные заголовки:

- Entertainment: «НАЙДИТЕ СВОЙ ВПЕЧАТЛЕНИЯ.» → «ВЫБЕРИТЕ / РАЗВЛЕЧЕНИЕ.»
- Brands: «ОТКРОЙТЕ / БРЕНДЫ.» → «ЗНАКОМЬТЕСЬ / С БРЕНДАМИ.»
- Dining hero: «ПОЕШЬТЕ. / ВСТРЕТЬТЕСЬ. / ОСТАНЬТЕСЬ.» → «ЕДА. / ВСТРЕЧИ. / БЕЗ СПЕШКИ.»
- Dining introduction: «СТОЛ / ДЛЯ КАЖДОГО / МОМЕНТА.» → «МЕСТО / ДЛЯ ЛЮБОЙ / ВСТРЕЧИ.»
- Dining directory: «НАЙДИТЕ СВОЙ / СТОЛ.» → «ВЫБЕРИТЕ / ЗАВЕДЕНИЕ.»
- Map и homepage preview: «НАЙДИТЕ / СВОЙ ПУТЬ.» → «НАЙДИТЕ / НУЖНОЕ МЕСТО.»
- CTA с названиями и категориями: «ПОДРОБНЕЕ CAVEA» → «ПОДРОБНЕЕ: CAVEA»; та же грамматика применяется к остальным заведениям.

Проверены категории: Cinema → «Кинотеатр», Bowling → «Боулинг», Fitness → «Фитнес», Kids entertainment → «Детские развлечения». Сами названия CAVEA, Bowling, Oktopus Fitness, Wonderland и остальных брендов не переводятся.
